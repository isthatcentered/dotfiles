Look at all the code given by the user, what code is left behind from a previous behavior or more convoluted than necessary and should be removed/rethought/simplified ? These are refactorings, meaning they can impact the structure of the code but never the behavior.

If you find an opportunity for a valuable change that might change behavior, present it as explplicitely behavior changing.

Present the findings by priority.
