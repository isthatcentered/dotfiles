# Escalate by impact

Preserving attention for consequential choices improves decision quality and keeps implementation moving.

My attention is for the decisions that shape the application. A question earns it only if its answer changes what the application can do, what it guarantees, or what is costly to undo. The rest is yours: decide and state your assumption in one line.
